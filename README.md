# Josh Thorpe Fitness & Injury Clinic — Premium Next.js Landing Page

Rebuilt as an editable Next.js + Tailwind site from the supplied visual reference. The reference screenshot is used only as a design reference; it is not used as a website image.

## Stack
- Next.js 16
- React 19
- Tailwind CSS 4
- `next/font/google` using Manrope
- Semantic HTML, accessible form labels and navigation
- Native `<img>` tags as requested

## Images
The site uses the supplied logo asset unchanged at `public/images/logo.png` and public/free-to-use Pexels image URLs for the photography. Source pages are documented in `IMAGE-SOURCES.md`.

## Run
```bash
npm install
npm run dev
```
